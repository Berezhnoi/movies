# Implementation Notes

This folder contains supporting records created during the design and implementation of the Movies API. These
materials document decisions, AI prompts, and security review work; they are not application source code and are
not read by the running service.

- [Prompt log](./prompts.txt) — prompts used to develop the authentication and authorization features, including Lesson 10 Tasks 2.1 and 2.2.
- [Security design](./security_design.txt) — roles, access rules, DTO boundaries, and security decisions.
- [Security audit](./security_audit.md) — reviewed findings, severity, and triage.
- [Lesson 10 design](./design_v10.txt) — web UI security, routing, embedding, and verification decisions.
- [Project specification](./PROJECT_SPEC.md) — architecture, API and web routes, configuration, security, and known limitations.
- [Agent guide](./AGENTS.md) — rules and workflow for AI coding agents working in this repository.
